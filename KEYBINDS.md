# Keybindings

## Gameplay

| Action | Keyboard | Gamepad |
|---|---|---|
| Move | Arrows / hjkl | D-pad |
| Jump | Space / Up / K | A or B |
| Crouch (toggle) | Down / J | D-pad Down |
| Shoot | Z | X |
| Aim lock (hold) | X | LB |
| Burrow (while crouching) | C | Y |
| Body panel | Tab | Start |
| Quit | Q | — |

## Body Panel (pause screen)

| Action | Keyboard | Gamepad |
|---|---|---|
| Switch panel | Tab | LB / RB |
| Navigate | Arrows / hjkl | D-pad |
| Pick up / place artifact | Z / Enter | A |
| Cancel hold / close | Esc | B / Start |

## Debug Menu (dev only)

| Action | Keyboard |
|---|---|
| Open / close | F1 |
| Navigate | Arrows / k / j |
| Toggle artifact | Z / Enter |
| Close | Esc |

## Artifacts

### Spiral Borer
Phase through solid floors while crouching. Burrowing is a commitment — ends only when you emerge below the floor.

| Action | Keyboard | Gamepad |
|---|---|---|
| Activate (while crouching) | C | Y |

### Wallbreaker
Passive. Your shots destroy solid tiles on impact. Without this artifact, bullets stop at walls but don't break them.

### Vampiric Cape
Passive. Leaves a spectral afterimage trail while moving. Each kill has a 1-in-3 chance to restore 1 HP.
