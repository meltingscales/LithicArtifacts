# Tile Prompts — Biome 1: Biomechanical

**Canvas:** 8×8 px per tile (seamlessly tileable)
**Depth:** shallowest biome — partial mechanical, partial biological
**Mood:** claustrophobic, alien, wrong. Metal bolted over wet muscle.
**Palette role:** very dark purple-gray fill, cold metallic or sickly green border

---

## Wall (solid block)
```
8x8 pixel art tile, biomechanical wall block, seamlessly tileable,
dark purple-gray fill, single-pixel cold metallic gray border,
surface detail: one or two rivet heads or bolt shapes,
faint organic texture underneath metal plating (wet, veined),
black void at edges where border is absent,
GBA retro pixel art, body horror, HR Giger adjacent, limited 16-color palette
```

## Wall — biological variant
```
8x8 pixel art tile, biomechanical wall block with exposed organic layer,
dark purple-gray with sickly green border highlight,
surface shows pulsing membrane or tube cross-section,
one small bioluminescent green dot or crack,
seamlessly tileable, GBA pixel art, body horror aesthetic
```

## Floor (walkable surface, top edge visible)
```
8x8 pixel art tile, biomechanical floor tile, top edge is the walkable surface,
dark purple-gray fill, metallic gray top-edge border (1–2px),
subtle grating or panel line across top third,
bottom blends to black, GBA retro pixel art, seamlessly tileable
```

## Pipe / conduit (decorative wall detail)
```
8x8 pixel art tile, biomechanical conduit or pipe running horizontally,
dark gray cylindrical pipe against black background,
sickly green or cyan fluid implied inside (single highlight pixel),
GBA retro pixel art, industrial body horror, seamlessly tileable horizontally
```

## Ceiling (solid, underside visible)
```
8x8 pixel art tile, biomechanical ceiling block,
dark purple-gray fill, metallic gray bottom-edge border,
drip of dark fluid implied at one corner (1–2 dark pixels),
GBA retro pixel art, seamlessly tileable
```
